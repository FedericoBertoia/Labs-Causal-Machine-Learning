0. Introduction

The goal of this lab is to estimate the Average Treatment Effect (ATE), defined as:

\[ E[Y^1 - Y^0], \]

where \(Y^a\) denotes the potential outcome had treatment been set to \(A = a\). Under the standard causal assumptions of consistency, positivity, and conditional exchangeability, the ATE is nonparametrically identified from observed data as:

\[ \text{ATE} = E\Big[E[Y \mid A=1, X] - E[Y \mid A=0, X]\Big]. \]

We implement and compare four estimators:

  1. G-Computation
  2. IPW (Inverse Probability Weighting)
  3. AIPW (Augmented IPW)
  4. TMLE (Targeted Maximum Likelihood Estimation)

Data

The dataset comes from an observational study conducted at Ohio Heart Health (1997), comprising 996 patients who underwent Percutaneous Coronary Intervention (PCI). Patients received PCI either with or without adjunct therapy using abciximab, a glycoprotein IIb/IIIa inhibitor that reduces platelet aggregation.

Importantly, abciximab was preferentially administered to more severely diseased patients, introducing confounding — a classic challenge in observational studies. All patients were followed for at least 6 months by the Lindner Center staff, and the binary outcome of interest is survival at 6 months (0 if survived, 1 otherwise).

2. Unadjusted Risk Difference and Odds Ratio

Before turning to “causal” estimators, we compute two simple unadjusted measures of association between treatment and outcome: the risk difference (RD) and the odds ratio (OR).

2.1 Risk Difference

The risk difference is the difference between the risk of an outcome in the treated group and non treated group.

\[ E[Y \mid A=1] - E[Y \mid A=0] = P(Y=1 \mid A=1) - P(Y=1 \mid A=0) \]

It can be estimated via a linear probability model:

\[ E(Y \mid A) = \alpha + \beta A \]

where \(\hat{\beta}\) directly estimates the risk difference.

2.2 Odds Ratio

The odds ratio is estimated via logistic regression:

\[ \text{logit}\, P(Y = 1 \mid A) = \log \frac{P(Y=1 \mid A)}{P(Y=0 \mid A)} = \alpha^* + \beta^* A \]

The odds ratio is then recovered as:

\[ \widehat{\text{OR}} = \frac{\color{green}{\text{odds}(Y=1 \mid A=1)}}{\color{blue}{\text{odds}(Y=1 \mid A=0)}} = \color{green}{\frac{P(Y=1 \mid A=1)}{P(Y=0 \mid A=1)}} \times \color{blue}{\frac{P(Y=0 \mid A=0)}{P(Y=1 \mid A=0)}} = \frac{\color{green}{\exp(\hat{\alpha}^* + \hat{\beta}^*)}}{\color{blue}{\exp(\hat{\alpha}^*)}} = \exp(\hat{\beta}^*) \]

4. G-Computation

G-Computation proceeds in two steps. First, fit an outcome model \(\hat{Q}(a, x) = \hat{E}[Y \mid A = a, X = x]\). Second, plug in \(A = 1\) and \(A = 0\) for every unit and average the difference in predicted potential outcomes:

\[ \widehat{\text{ATE}}_{\text{G-comp}} = \frac{1}{n} \sum_{i=1}^{n} \left[ \hat{Q}(1, X_i) - \hat{Q}(0, X_i) \right]. \]

4.1 Parametric outcome model

We first fit a parametric logistic regression for \(Q(a, x)\) and obtain the ATE by hand. Standard errors are then computed via stdReg, which uses a sandwich estimator for the variance of \(\hat{E}[Y^1]\) and \(\hat{E}[Y^0]\):

\[ \widehat{\text{var}}\left(\hat{E}[Y^1 - Y^0]\right) = \widehat{\text{var}}\left(\hat{E}[Y^1]\right) + \widehat{\text{var}}\left(\hat{E}[Y^0]\right) - 2\,\widehat{\text{cov}}\left(\hat{E}[Y^1], \hat{E}[Y^0]\right) \]

# ── Model formula ─────────────────────────────────────────────────────────────
formula_gcomp <- as.formula(paste("Y ~ A +", paste(colnames(X), collapse = " + ")))

# ── Fit parametric outcome model ──────────────────────────────────────────────
glm_Q <- glm(formula_gcomp, family = binomial(), data = data.frame(Y, A, X))

# ── Predict potential outcomes by hand ───────────────────────────────────────
dat0 <- data.frame(Y, A = 0, X)
dat1 <- data.frame(Y, A = 1, X)

Q0_par <- predict(glm_Q, newdata = dat0, type = "response")
Q1_par <- predict(glm_Q, newdata = dat1, type = "response")

ate_gcomp_par <- mean(Q1_par - Q0_par)
cat("G-Computation ATE (parametric, by hand):", round(ate_gcomp_par, 4), "\n")
## G-Computation ATE (parametric, by hand): -0.0452
# ── Standard error via stdReg (sandwich estimator) ────────────────────────────

4.2 Non-parametric outcome model (Super Learner)

We now replace the parametric logistic regression with a Super Learner ensemble, which avoids model misspecification but introduces plug-in bias — nonparametric estimators converge at slower rates, making valid confidence intervals unavailable in this setting.

# ── Without cross-fitting ─────────────────────────────────────────────────────
sl_Q <- SuperLearner(
  Y          = Y,
  X          = data.frame(A = A, X),
  SL.library = SL.library,
  family     = binomial(),
  method     = "method.NNLS",
  cvControl  = list(V = 5)
)

Q1 <- predict(sl_Q, newdata = data.frame(A = 1, X))$pred
Q0 <- predict(sl_Q, newdata = data.frame(A = 0, X))$pred

ate_gcomp <- mean(Q1 - Q0)
cat("G-Computation ATE (no cross-fitting):", round(ate_gcomp, 4), "\n")
## G-Computation ATE (no cross-fitting): -0.026

Q1_cf <- numeric(N)
Q0_cf <- numeric(N)

5. IPW

The Inverse Probability Weighting (IPW) estimator reweights observations by the inverse of their propensity score \(\hat{\pi}(x) = \hat{P}(A = 1 \mid X = x)\), upweighting units whose treatment assignment was unlikely given their covariates.

\[ \widehat{\text{ATE}}_{\text{IPW}} = \frac{1}{n} \sum_{i=1}^{n} \left( \frac{A_i Y_i}{\hat{\pi}(X_i)} - \frac{(1-A_i) Y_i}{1 - \hat{\pi}(X_i)} \right) \]

An alternative is the Hájek (self-normalized) IPW estimator, which normalizes the weights within each treatment arm:

\[ \widehat{\text{ATE}}_{\text{Hájek}} = \hat{E}[Y^1] - \hat{E}[Y^0] = \frac{\sum_{i=1}^{n} \frac{A_i}{\hat{\pi}(X_i)} Y_i}{\sum_{i=1}^{n} \frac{A_i}{\hat{\pi}(X_i)}} - \frac{\sum_{i=1}^{n} \frac{1-A_i}{1-\hat{\pi}(X_i)} Y_i}{\sum_{i=1}^{n} \frac{1-A_i}{1-\hat{\pi}(X_i)}} \]

This is equivalent to a weighted linear regression of \(Y\) on \(A\) with stabilized weights \(w_i = A_i/\hat{\pi}(X_i) + (1-A_i)/(1-\hat{\pi}(X_i))\), since lm() internally normalizes weights within each group. The Hájek estimator is generally preferred in finite samples as it is less sensitive to extreme propensity scores.

5.1 Parametric propensity score model

We first estimate \(\hat{\pi}(x)\) using a parametric logistic regression. The ATE is obtained via a weighted linear regression of \(Y\) on \(A\), with stabilized IPW weights \(w_i = A_i / \hat{\pi}(X_i) + (1 - A_i) / (1 - \hat{\pi}(X_i))\). Standard errors are computed using the heteroskedasticity-consistent HC sandwich estimator.

6. AIPW

The Augmented IPW (AIPW) estimator combines the outcome model and the propensity score into a single doubly robust estimator: it remains consistent if either (but not necessarily both) nuisance models are correctly specified.

\[ \widehat{\text{ATE}}_{\text{AIPW}} = \frac{1}{n} \sum_{i=1}^{n} \left[ \hat{Q}(1, X_i) - \hat{Q}(0, X_i) + \frac{A_i (Y_i - \hat{Q}(1, X_i))}{\hat{\pi}(X_i)} - \frac{(1 - A_i)(Y_i - \hat{Q}(0, X_i))}{1 - \hat{\pi}(X_i)} \right] \]

7. TMLE

Targeted Maximum Likelihood Estimation (TMLE) is a doubly robust, asymptotically efficient substitution estimator. Rather than directly correcting the plug-in bias as AIPW does, TMLE updates the initial outcome model $\hat{Q}$ through a targeted fluctuation step driven by the propensity score, ensuring the final estimate solves the efficient score equation exactly. We illustrate two implementations: the `tmle` package and a manual derivation that makes the fluctuation step explicit.

7.1 tmle Package

7.2 manual TMLE

# ── Clever Covariates ─────────────────────────────────────────────────────────
H1 <- A / pi_hat_cf
H0 <- (1 - A) / (1 - pi_hat_cf)

# ── Estimate fluctuation parameters ──────────────────────────────────────────
delta1 <- coef(glm(Y ~ -1 + offset(qlogis(Q1_cf)) + H1, family = binomial()))
delta0 <- coef(glm(Y ~ -1 + offset(qlogis(Q0_cf)) + H0, family = binomial()))

# ── Update initial predictions ────────────────────────────────────────────────
Q1_cf_updated <- plogis(qlogis(Q1_cf) + delta1 / pi_hat_cf)
Q0_cf_updated <- plogis(qlogis(Q0_cf) + delta0 / (1 - pi_hat_cf))

# ── ATE estimate ──────────────────────────────────────────────────────────────
ate_tmle_cf_manual <- mean(Q1_cf_updated - Q0_cf_updated)

# ── Efficient Influence Function and standard error ───────────────────────────
eif <- (Q1_cf_updated - Q0_cf_updated - ate_tmle_cf_manual) +
        A / pi_hat_cf * (Y - Q1_cf_updated) -
        (1 - A) / (1 - pi_hat_cf) * (Y - Q0_cf_updated)

se_tmle_cf_manual  <- sd(eif) / sqrt(N)
ci_tmle_cf_manual  <- ate_tmle_cf_manual + c(-1, 1) * 1.96 * se_tmle_cf_manual

cat("TMLE ATE (cross-fitting, manual):", round(ate_tmle_cf_manual, 4), "\n")
## TMLE ATE (cross-fitting, manual): -0.062
cat("SE:", round(se_tmle_cf_manual, 4), "\n")
## SE: 0.0258
